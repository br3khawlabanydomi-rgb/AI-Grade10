Explanation and examples

Critical evaluation judges an output against explicit criteria rather than by impression, and a mature judgement names both strengths and weaknesses - most outputs are mixed. Three criteria matter here: accuracy (is the content true when checked against a trusted source), fairness (does it treat groups even-handedly, without bias), and usefulness (does it actually help complete the task). A model generates text by predicting likely tokens, not by knowing what is true or fair, so a fluent, confident output can be accurate yet biased, or useful yet wrong. In an integrated AI system the strength or weakness rarely sits in the model alone - the data, the prompt, or the choice of tool each shapes the result. Skilled evaluators cite specific evidence for every judgement and trace it to the component behind it, so the whole solution can be improved rather than merely re-run.

Source activity

Hands-on activity guide Overview: Pairs act as an evaluation panel, judging a curated set of AI outputs for one task against the agreed criteria, naming the strengths and weaknesses of each with evidence, and tracing every judgement to the system component behind it. Grouping / timing: Pairs for the judging; whole class for the agree-the-criteria opener and the evidence debrief. Tool: A teacher pre-generated output set on paper or the board (account-free, no student logins). All outputs are produced in advance by the teacher on a school-approved, child-safe tool, with no personal data - no names, faces or voices - entered into any prompt, and no student operating a live model. Facilitation steps: 1. As a class, agree the criteria you will judge against: accuracy, fairness and usefulness. 2. Read the task the outputs were meant to complete, so you know what a strong result looks like. 3. For each curated output, name at least one strength and one weakness, giving a verdict against every criterion. 4. For every strength and weakness, write one piece of evidence - the exact word, fact or step that shows it. 5. Verify one output against a trusted source to test whether a confident answer is actually accurate and fair. 6. Name the component behind each strength or weakness - data, prompt or tool - and share your clearest judgement with the class. Unplugged fallback: If no tool or display is available, use the printed card set: each card is a pre-written output for the same task, and pairs annotate each card with a strength sticky note and a weakness sticky note, each carrying its evidence and a component tag.
