Explanation and examples

A simple AI solution is a workflow - an ordered sequence of steps that turns an input into a useful output for a specific task - not a single magic step. Each step has a defined input and output, and at least one step uses an AI tool such as a generator or a classifier. Designing at this level is systems thinking in miniature: decompose one specific task, decide what each step needs and produces, and reason about how the output of one step becomes the input of the next. Building is composing and configuring these steps so they connect reliably, not training a model from scratch. Explaining the result means tracing an output back to the step that produced it, and applying verify-before-trust - a confident output can still be wrong, so it is checked against the task and a trusted source. Verify before you trust: judge the output against the task, then trace back to the step that produced it.

Source activity

Hands-on activity guide Overview: Pairs design and build a simple three-step AI workflow that completes one specific task, then run it and explain the reasoning behind the result, using a card-based simulated AI so no accounts or personal data are needed. Grouping / timing: Pairs for the design and build, whole class for the debrief. Tool: A simulated-AI card deck of pre-generated, non-personal output cards prepared by the teacher stands in for the AI tool step - account-free, no personal data, and it works even with no devices. If a device is used it is the school-approved tool, teacher-operated on the board only. Facilitation steps: 1. Choose one specific task from the task menu, for example turn ten anonymised event notes into a short sorted summary. 2. Break the task into three ordered steps, and for each step write what its input is and what its output should be. 3. Mark which step is the AI tool step, and place the tool card that matches the instruction for that step. 4. Run the workflow step by step, feeding the output of each step in as the input of the next, and record the output at each stage. 5. Judge the final output against the specific task and a trusted reference using verify-before-trust. 6. Explain the reasoning behind the result - which step produced it - and note one step you would change to improve it. Unplugged fallback: The whole activity is already unplugged using paper cards. For a fully human version, one student acts as the AI tool step and follows the pair's written instruction exactly, using only the supplied input, while the others check whether each step's output completes the specific task.
