Explanation and examples

A single AI tool maps one input to one output. Real solutions rarely fit one tool, so designers connect several into a pipeli ne (also called a workflow or a chain): the output of one component becomes the input of the next. A study -support solution might chain speech-to-text, then a language model that summarises, then a checker that flags uncertain claims. Each component has a clear job, a defined input and a defined output, and something - orchestration logic - decides the order and passes the data along. Systems thinking matters because behaviour emerges from how the parts interact: an error early in the chain propagates downstream, and the whole can do more, or fail in new ways, than any single part. Understanding the connections, not just the parts, is the skill this phase builds.

Source activity

Hands-on activity guide Overview: Students investigate two teacher-provided worked examples of multi-tool solutions, map how inputs become outputs at each stage, and explain the reasoning to a partner. Grouping / timing: Pairs for the mapping and the explain-back; whole class for the debrief. Tool: A teacher-mediated pipeline card set: pre-printed cards showing each component with its sample input and output, arranged on the desk. No student accounts and no live tools - the AI outputs are pre-generated and curated by the teacher, and no personal data is ever entered. Facilitation steps: 1. Read the worked example card set your teacher hands out - it shows a real multi-tool solution broken into components. 2. Lay the cards in order and draw an arrow from each component's output to the next component's input. 3. For each arrow, write in one line what data is being passed along. 4. Mark one stage where a wrong output would spread downstream, and note how you would check it (verify before trust). 5. Explain your whole map to your partner in your own words, using the terms pipeline, component and orchestration. 6. Swap roles: listen to your partner's example and challenge one hand-off you are unsure about. Unplugged fallback: The task is already account-free and paper-based. If the cards are unavailable, students sketch the same pipeline from the board example on a mini-whiteboard, labelling each input and output by hand.
