Explanation and examples

No single AI tool is best at everything. Real solutions are built by combining tools so that the output of one becomes the input of the next - a pipeline, or tool chain. A photo can pass to an image -to-text tool, whose text passes to a translation tool, whose output passes to a text-to-speech tool, so several narrow tools together do what none does alone. Systems thinking is the habit of seeing the whole solution - the tools, the order and the hand-offs between them - rather than one clever app. This launch lesson surfaces what students know about single tools and reframes solutions as integrated, multitool systems; it does not yet build one. It also flags that errors can compound: a mistake at an early hand-off flows downstream, so verify-before-trust matters at every step. Keep all tool use teacher-operated, account-free and free of personal data. Cognitive demand for this lesson: Understand/Analyse | DOK 2-3 | SOLO: Uni to Multistructural.

Source activity

Hands-on activity guide Overview: The class opens the unit with a curated stimulus that reveals a multi-tool solution as a chain of tools handing work to each other, then explores and sorts example cards as single-tool or integrated multi-tool and names the hand-offs, before co-building the vocabulary wall and safe-use charter and previewing the signature activity. Grouping / timing: Pairs for the sort, whole class for the wall, charter and debrief. Tool: A teacher-operated board demo plus a pre-printed, curated card set (a 'simulated AI' paper routine that shows real tool outputs already generated). Account-free and no personal data - students never log in or enter names, faces or voices. Facilitation steps: 1. Watch the stimulus and note one tool you noticed and one thing you wonder. 2. Turn your wondering into at least two clear questions about how different tools can be used together. 3. With your partner, sort each card as single-tool or integrated multi-tool. 4. For each multi-tool card, write which tool's output feeds the next tool (the hand-off). 5. Add one word and its meaning to the class vocabulary wall. 6. Propose one responsible-use rule for our safe-use charter, including verifying outputs at each step. Unplugged fallback: The whole lesson already runs unplugged on paper cards and a board demo. If the demo tool is unavailable, describe one worked pipeline aloud, name each tool and hand-off, and have pairs sort the printed cards and draw the arrows - no device needed. Reveal a task that needs several tools and show each narrow tool doing one part; agree that combining tools solves problems no single tool handles, and that the skill is arranging them, not finding one super-tool. Combining more tools always makes the solution better. Show an integrated solution where an unnecessary tool adds nothing or introduces an error at a hand-off; agree that tools are added because the task needs them, and each added step is a place a mistake can enter.
